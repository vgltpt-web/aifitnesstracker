# 🏋️ FitNova AI - Fitness Tracking Website

## 📖 Overview
FitNova AI is a fitness-focused web application designed to help users achieve their health and fitness goals through personalized workout plans, BMI tracking, trainer guidance, and membership programs.

## ✨ Features
- 🏃 Personalized Workout Plans
- 📊 BMI Calculator
- 👨‍🏫 Professional Trainer Profiles
- ⭐ Customer Reviews
- 💰 Membership Pricing Plans
- 🎥 Fitness Motivation Video
- 📱 User-Friendly Interface

## 🛠️ Technologies Used
- HTML5
- Tables
- Forms
- Images
- Iframes
- Hyperlinks

3. Run the `aifetnesswebsite.html` file in any web browser.
